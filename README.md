# OsmAnd GPSRadar — чистый исходный OsmAnd + камеры

Новая независимая линия разработки. Здесь **нет** кода и интерфейса Pongo.
Основа Android-приложения: `osmandapp/OsmAnd`, оригинальный исходный код.
Наши дополнения хранятся в `gpsradar/` и при сборке накладываются на свежий upstream.

## Решения пользователя
- Оригинальный интерфейс OsmAnd и все его профили, маршруты и карты сохраняются.
- Карта: все точки из загруженной базы показываются маленькими тематическими значками.
- GPSRadar: предупреждения о приближении, лимите скорости и средней скорости, с реальными показателями.
- Профили: truck — грузовая база; car, motorcycle, bus — легковая; остальные по выбору.
- Переключатель предупреждений «Штатные / Расширенные» хранится по профилям.
- Виджет «GPSRadar — предупреждения» регистрируется как обычный виджет OsmAnd и может стоять слева, справа, сверху или снизу.
- Базы скачиваются **только по явному нажатию** в «Карты и ресурсы» > «Камеры контроля скорости» > «Европа» > «Легковые/Грузовые».
- Используются HTTPS URL site `slagboom.narod.ru/gpsradar/manifest.json`, `car.zip`, `truck.zip`; формат должен быть проверен на реальных ZIP.
- Никаких автоматических скачиваний и фоновых сетевых запросов за обновлениями.
- Не запускать GitHub Actions или компилятор до отдельного разрешения.

## Текущая стадия
Проектный каркас и код ядра камеры, не готовый APK. Пункты интеграции в API виджетов, карт и штатных предупреждений OsmAnd требуют разработки и проверки.
